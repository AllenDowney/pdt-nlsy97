# pdt-nlsy97

Metadata for the [National Longitudinal Survey of Youth 1997 (NLSY97)](https://www.nlsinfo.org/content/cohorts/nlsy97), built to the [PublicDataToolkit](https://github.com/AllenDowney/PublicDataToolkit) standard.

**Status:** a slice of 25 questions from the 1997–2023 cohort file (rounds 1–21), built locally. The terms are decided (everything ships), but nothing is published yet.

## What the dataset is

BLS's panel survey of about 9,000 people born in 1980–84, interviewed every year from 1997 to 2011 (rounds 1–15) and every two years since (rounds 16–21, 2013–2023); managed by CHRR at The Ohio State University.

NLS publishes the cohort as one wide file: one column per *reference number*, and each reference number is one question in one survey year. YHEA-100 (general health) is R0320600 in 1997 and another reference number in each later year. This repo turns that into two tables:

| Table | Rows | Key | What |
|---|---|---|---|
| `person` | 8,984 | PUBID | questions asked once (sex, birth date, race and ethnicity, sample type) and the variance stratum and PSU |
| `person_year` | 188,664 | PUBID, SURVEY_YEAR | one row per respondent and survey year: the weight, education, income, marital status, weeks worked, health, the MHI-5 items, smoking and drinking |

A record is a question name. Its `availability` lists the years it was asked, `questions` each wording with its years, and `source_columns` its reference number in each year. A year in which a question wasn't in the file is empty in `person_year`; a year in which the respondent wasn't interviewed has NLS's code -5.

### Answers spread across rounds

A person's answer about a year, or at an age, can be in a different round than the obvious one: rounds went from annual to every two years, people miss rounds and come back, and many questions ask about the time since the last interview. [`AGENT_NOTES.md`](AGENT_NOTES.md) says how NLS's data work, what NLS recommends (interview dates, created variables, event history arrays), and how often it happens in this slice. It's also in `agent/SKILL.md`. With the PublicDataToolkit library, `pdt.panel` lists every round's answer that could be a person's answer about a year or at an age, each with its round, reference period and overlap or distance, and never chooses among them; `pick` applies a policy you name.

## Terms of use

Allen Downey reviewed the terms on 2026-11-20: the metadata, the documentation and the common-format data ship, with this notice:

> Source: Bureau of Labor Statistics, U.S. Department of Labor, National Longitudinal Survey of Youth 1997 cohort, public-use data, rounds 1-21. Cite as NLS suggests: https://www.nlsinfo.org/bibliography/citing-nls-data.

NLS public-use data are free and posted for download; NLS asks to be cited (https://www.nlsinfo.org/bibliography/citing-nls-data). [`dataset.yaml`](dataset.yaml) quotes what NLS says.

## How to get the data

The files are listed in [`sources.yaml`](sources.yaml), with where to get each and its checksum: one 475 MB zip, whose CSV is 8.1 GB. Then copy the slice's columns out of it and write the tables (each step runs under a 6 GB memory cap):

```bash
make download ARGS=--accept-terms
make extract     # the slice's codebook entries and columns into data/interim, about 5 minutes
make build
make data
```

## How to use the metadata

- `metadata/releases/1997-2023/<table>/variables.jsonl`: one record per question, with where each fact came from.
- `docs/`: a page per variable, generated by `make views`.
- `agent/`: shards for LLMs; start with `agent/SKILL.md`.

## How to cite

Bureau of Labor Statistics, U.S. Department of Labor. National Longitudinal Survey of Youth 1997 cohort, 1997-2023 (rounds 1-21). Produced and distributed by the Center for Human Resource Research (CHRR), The Ohio State University. Columbus, OH.

## How to rebuild

With the sources in `data/raw/` and a PublicDataToolkit checkout next to this repo:

```bash
make build
make data
make views
make check
```

The metadata tools (`make views`, `make check`) need only the toolkit's base install
(`pip install -e ../PublicDataToolkit`). Building or reading the data files (`make data`,
`scripts/extract.py` where the repo has one, and the data checks in `make check`) also
needs pandas, numpy and pyarrow: `pip install -e "../PublicDataToolkit[data]"`. Without
them, `make check` skips the data checks and says why.
